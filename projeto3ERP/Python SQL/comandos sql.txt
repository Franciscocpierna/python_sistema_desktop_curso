**Dica:** Se o sistema der erro de "Table doesn't exist", certifica-te de que o nome da tabela no Python é exatamente `clientes` (ou o nome que definiste no `CREATE TABLE`). O SQL diferencia letras maiúsculas e minúsculas dependendo da configuração do sistema.

CREATE TABLE python.cliente (
id INT NOT NULL AUTO_INCREMENT,
nome VARCHAR(50) NOT NULL,
telefone VARCHAR(50) NULL,
cidade VARCHAR(50) NULL, -- Removi a vírgula que estava aqui
PRIMARY KEY (id)         -- A chave primária deve ficar dentro dos parênteses
);
